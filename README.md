# 汉语 · Chinese / Китайский: учебник 1–16 и HSK

Статическое приложение для повторения китайского: уроки, словарь, карточки, тесты, сборка фраз и свободная пропись. Основной файл — `index.html`. Интерфейс и переводы на русском.


## Русский и English

Кнопка **English / Русский** в шапке переключает интерфейс, значения слов, вопросы теста, переводы фраз и пояснения. Выбор сохраняется в `cc2-language`. Китайские слова, пиньинь, русские исходные данные и прежние ключи прогресса сохранены. Поиск работает по китайскому, пиньиню, русскому и английскому переводу.

**Инфо → Экспорт / Импорт прогресса** позволяет перенести отметки между браузерами и доменами. Импорт объединяет записи и не заменяет более новый счётчик ответов старым. Прогресс временно закрытого курса не удаляется при обучении в доступном курсе.

## Два режима запуска

- **GitHub Pages или `python3 -m http.server`**: прежняя открытая версия, все материалы доступны. В ней нет ограничения покупателей; скрытие кнопок не считается защитой.
- **`server:create_app()` на собственном HTTPS-хостинге**: сервер проверяет подпись Telegram `initData` и права в SQLite до выдачи учебных данных. Бесплатны уроки 1–3; закрытые материалы и их переводы не включаются в HTML и не выдаются API без разрешений. Отдельной раздачи исходников и JSON нет.

Владелец использует `/admin` в личном чате с ботом: заявки, ученики, пакеты, 30 дней или бессрочно, отзыв пакета и блокировка аккаунта. Владельцы задаются только числовыми ID в переменной `ADMIN_IDS`. Авторизованный владелец имеет полный доступ. Приложение перепроверяет права раз в минуту и при возвращении на экран.

**[Подробная инструкция первого запуска → DEPLOY.md](DEPLOY.md)**. В репозитории есть `render.yaml` для платного сервиса с постоянным диском, но его слияние не создаёт хостинг и не списывает деньги.

Реального токена, владельца или размещённого сервера в коде нет. Автоматические платежи, проверка переводов, выставление счетов и интеграция Stars **не включены**. Подготовлена ручная выдача курсов. До коммерческого запуска нужно отдельно подключить оплату и проверить права на учебные материалы.

Нельзя отозвать уже скопированную открытую базу из GitHub или стереть загруженный материал с устройства пользователя. Сервер контролирует последующие выдачи; блокировка Telegram-аккаунта не отключает анонимный пробный просмотр и другие аккаунты человека.

## Проверки разработки

Серверные тесты используют стандартную библиотеку Python и не обращаются к Telegram:

```sh
python3 -m unittest discover -s tests -v
```

Для воспроизводимой проверки интерфейса установите Playwright как инструмент разработки, запустите статический HTTP-сервер на порту 8000 и выполните:

```sh
npm install --no-save playwright
npx playwright install chromium
node tests/browser.cjs
```

Для системного Chromium можно задать `CHROMIUM_PATH`. Можно передать `HANZI_TEST_URL` с другим адресом **открытой статической версии**. Этот тест проверяет русский/английский, обучение, восстановление языка и размеры экрана. Серверная авторизация, пакеты, истечение срока, повторные доставки команд, отзыв, блокировка и сохранность базы проверяются Python-тестами. Тестовый токен в них фиктивный и не подключает настоящего бота.

## Запуск

Зависимости и сборка не нужны. Из корня репозитория:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Открыть http://localhost:8000. GitHub Pages может публиковать `main` из `/ (root)`.

## Курсы

Переключатель «Курс» доступен над содержимым. Раздел «Уроки» содержит подборки слов, прогресс, краткую грамматику и переходы к тренировке.

- **汉语教程, уроки 1–16.** Исходная база 1–13 сохранена без изменений. Добавлены подборки к урокам 14 «你的车是新的还是旧的», 15 «你家有几口人» и 16 «你常去图书馆吗»: 18, 28 и 38 карточек соответственно, включая повторение ранее встречавшихся слов. Урок 16 относится к первому тому, части 2. Это ключевая лексика и авторские упражнения, а не полный перенос печатного учебника. Привязки старой базы 1–13 и полнота новых подборок не заявляются как результат постраничной сверки.
- **HSK 1, новая программа.** 300 нумерованных словарных позиций программы экзамена ноября 2025 года.
- **HSK 2, новая программа.** HSK 1 + 200 новых позиций: 500 позиций, 497 карточек после объединения одинакового написания. Разные чтения и значения сохранены, в частности 过 guò / guo и 花 «тратить» / «цветок». В фильтрах есть «Только новые HSK 2».

HSK разбит на учебные блоки по 30 карточек. Это группировка приложения, а не нумерация уроков официального учебника. Краткая грамматика и 24 упражнения на сборку фраз — авторская практика по уровням, а не полный пробный экзамен. Для новых уроков учебника добавлено ещё 12 фраз. Фразы HSK выбираются по уровню; выбор словарного блока не ограничивает фразы. Для уроков учебника 14–16 доступны отдельные наборы фраз; остальная практика учебника общая.

- [Официальная программа HSK](https://www.chinesetest.cn/syllabus).
- [PDF программы](https://hsk.cn-bj.ufileos.com/3.0/%E6%96%B0%E7%89%88HSK%E8%80%83%E8%AF%95%E5%A4%A7%E7%BA%B21219.pdf): позиции 1–500, физические страницы 80–91. Сопоставлены начало и конец диапазонов, написания и чтения омографов.
- Китайский список, пиньинь, номера позиций и страницы взяты из [машиночитаемой транскрипции hsk-tutor.com](https://github.com/uranbekanarbaev/hsk-3.0-vocabulary-dataset/blob/main/SOURCES.md): `data/by-level/hsk-1.json` и `hsk-2.json`. Оригинальные права на программу принадлежат её правообладателям; лицензия программного кода источника не распространяется на материалы экзамена. Код, диалоги, аудиозаписи и шаблоны стороннего приложения не переносились. Русские пояснения, переводы и упражнения составлены для этого приложения.
- [Издатель: 汉语教程, 3-е издание, первый том, часть 2](https://www.blcup.com/PInfo/index/8660).
- [Учебный курс с названиями уроков 14 и 15](https://mooc.klw.ac.th/courses/%E0%B8%A7%E0%B8%B4%E0%B8%8A%E0%B8%B2%E0%B8%A0%E0%B8%B2%E0%B8%A9%E0%B8%B2%E0%B8%88%E0%B8%B5%E0%B8%99-2-%E0%B8%8A%E0%B8%B1%E0%B9%89%E0%B8%99%E0%B8%A1%E0%B8%B1%E0%B8%98%E0%B8%A2%E0%B8%A1%E0%B8%A8/).
- [Материалы преподавателя к уроку 16](https://mooc.klw.ac.th/wp-content/uploads/2022/02/%E6%B1%89%E8%AF%AD%E6%95%99%E7%A8%8B1%E4%B8%8B%E8%AF%BE%E4%BB%B6L16.pdf): темы частоты, совместных действий, подготовки к занятиям, общения и свободного времени. Подборки дополнены повторением и не заявлены как полный словарь уроков.

## Сохранение

Прогресс остаётся в `localStorage` под прежним ключом `cc2`. Он общий для одинакового китайского написания во всех курсах; прежние отметки и счётчики не сбрасываются. Настройки карточек остаются в `cc2-settings`, выбор курса и его фильтры — в `cc2-courses`. Кнопка сброса с подтверждением удаляет прогресс всех курсов.

Прогресс автоматически не переносится между браузерами и устройствами. Telegram SDK и озвучка зависят от среды и сети. Пропись свободная: приложение не оценивает написание и порядок черт.

## Черты и ключи

В меню добавлены независимые от курса разделы **«Черты»** и **«Ключи»**.

- **Черты:** 19 учебных форм, китайское название, пиньинь, русское пояснение, пример иероглифа, авторская SVG-схема и показ направления движения. Это учебная подборка, не исчерпывающая классификация всех черт китайской письменности. Схемы показывают движение центральной линии и не являются каллиграфическими образцами.
- **Ключи:** все 214 ключей Канси в традиционной нумерации, пиньинь и русские значения; для распространённых ключей — позиционные/упрощённые формы, примеры и дополнительные пояснения. Число черт относится к традиционной форме: например, 言 имеет 7 черт, а его упрощённая форма 讠 — 2. Ключ — категория словарной классификации, а не любое графическое сочетание и не гарантированный перевод иероглифа.
- Поиск по символу, названию, пиньиню без тонов, русскому значению или номеру. Поиск по номеру использует подстроку; например, «14» найдёт и №14, и №140. В ключах есть фильтр числа черт.
- Отметки «Знаю», «Путаю», «Не знаю» и фильтры новых, освоенных и требующих повторения. «К повторению» объединяет «Путаю» и «Не знаю»; календарного расписания нет.
- Тесты по выбранным фильтрам: до 10 вопросов, четыре варианта ответа, результат и повторение ошибок. Правильный ответ отмечает элемент как «Знаю», ошибка — «Не знаю».
- Свободная пропись для черт и ключей с образцом, отменой последнего штриха и очисткой. Автоматической оценки точности и порядка черт нет. У ключей показан целый символ; анимации порядка его черт нет.

Прогресс элементов хранится **отдельно** в `cc2-hanzi-elements-v1` и сохраняется после перезагрузки. Старые ключи `cc2`, `cc2-settings`, `cc2-courses` и словарные данные сохранены. Кнопка сброса прогресса курсов не удаляет отметки черт и ключей. Фильтры и незавершённые тесты элементов действуют до перезагрузки. Озвучка названий использует имеющийся китайский голос браузера.

Источники для сверки классификации и названий:

- [Unicode, Kangxi Radicals U+2F00–U+2FD5](https://www.unicode.org/charts/PDF/U2F00.pdf): порядок и состав 214 ключей. Таблицы PDF и шрифтовые контуры не встроены в приложение.
- [Unicode 17, Appendix F: Documentation of CJK Strokes](https://www.unicode.org/versions/Unicode17.0.0/core-spec/appendix-f/): терминология и названия черт. SVG-траектории и русские инструкции составлены для приложения.
- [HSK Guide, Radical library](https://www.hsk.guide/radicals): дополнительная сверка чтений. В карточках выбраны чтения названий ключей, которые могут отличаться от чтений современного самостоятельного слова: например, 厂 hǎn как ключ и chǎng «завод», 广 yǎn как ключ и guǎng «широкий».

Проверка: `node tests/elements.cjs` при установленном Playwright и Chromium. Необязательные переменные: `CHROMIUM_PATH` (исполняемый файл браузера), `HANZI_SCREENSHOT_DIR` (каталог снимков). Тест подставляет локальный HTML, блокирует внешние запросы, проверяет оба каталога, поиск, фильтры, тесты, пропись, восстановление отметок, сохранность прежнего словаря и мобильную ширину 360/390 px. Звук на слух и работа на реальном iPhone не проверялись.

Английский интерфейс сохранён; новые названия и описания также переведены. Поиск в каталогах работает и по английским значениям. Каталоги — общедоступная справка, отдельная от доступа к словарным курсам; заблокированный Telegram-аккаунт по-прежнему видит экран ограничения. Экспорт/импорт прежнего прогресса словаря не включает отметки элементов.

## Для Codex

Выбрать этот репозиторий и ветку `main`. Запустить HTTP-сервер командой выше. Проверять переключение курсов, фильтры уроков и блоков, поиск, карточки, тесты, сборку фраз, пропись и восстановление старого прогресса. Сохранять русский интерфейс, исходные учебные данные и ключи хранилища. Изменения оформлять в отдельной ветке и pull request.

Серверные зависимости находятся в `requirements.txt`; они не нужны для открытой статической версии. Для production используется Gunicorn, один worker с HTTP-потоками и один процесс polling бота. Ключи окружения перечислены в `.env.example`; этот файл не загружается автоматически.
