# 汉语 · Китайский 1–13

Статическое приложение для повторения китайского: словарь, карточки, тесты, фразы и пропись. Основной файл — `index.html`.

## Запуск

Зависимости и сборка не нужны. Из корня репозитория:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Открыть http://localhost:8000. Прогресс сохраняется локально в браузере; при смене браузера он автоматически не переносится. Telegram SDK и озвучка зависят от среды и сети.

## Для Codex

Выбрать этот репозиторий и ветку `main`. Установка зависимостей не требуется. Команда запуска приведена выше.

Задание: «Запусти приложение из index.html через HTTP-сервер. Проверь поиск, карточки, тест, сборку фраз, пропись и сохранение прогресса. Покажи превью. Исправляй только подтверждённые ошибки; сохраняй словарь и русский интерфейс».
